# 🤖 Nier: Automata (Team Project)

PlatinumGames의 3D 액션 RPG **Nier: Automata** 모작 팀 프로젝트입니다.  
3D 액션 전투 구현을 중심으로 Enemy AI, Boss 패턴, 전투 흐름 시스템을 설계 및 구현했습니다.

---

## 📌 Project Info
- 개발 인원 : 5인 (프로그래머 5인)
- 개발 기간 : 2023.05 ~ 2023.06
- 개발 환경 : Unity3D, C#
- 담당 역할 : Enemy AI 및 Boss 전투 시스템 구현

## 🧠 핵심 구현 요소

- Enemy AI 상태 기반 로직 구현 (Idle / Trace / Attack / Dead)
- Boss 패턴 설계 및 전투 흐름 제어 시스템 구현
- 공격 / 피격 / 경직 / 데미지 처리 로직 구현
- 컷씬 및 이벤트 연출 시스템 구현
- UGUI 기반 전투 UI 구성
- Object Pool 기반 Enemy 및 이펙트 최적화
- Singleton 기반 Battle Manager 구조 설계

---

## 🔧 Core Systems (담당 파트 중심)

- Enemy State Machine 구현
- Boss Pattern Controller 설계
- Combat Interaction System 구현
- Battle Flow Manager 구조 설계
