## 🤖 Nier: Automata (Team Project)

> 3D 액션 전투 중심 게임 모작 프로젝트  
> Enemy AI, Boss 패턴, 전투 시스템 구현을 중심으로 개발

• 기간: 2023.05 ~ 2023.06  
• 환경: Unity3D, C#  
• 인원: 5인 (프로그래머 5인)  

### 🔧 Core Implementation
- Enemy AI 상태 로직 및 행동 패턴 구현
- Boss 패턴 및 전투 흐름 시스템 설계
- 공격, 피격, 전투 상호작용 로직 구현
- 컷씬 및 이벤트 연출 시스템 구현
- UGUI 기반 전투 UI 개발
- Object Pool 기반 Enemy 및 이펙트 최적화
- Singleton 구조를 활용한 전투 매니저 설계
